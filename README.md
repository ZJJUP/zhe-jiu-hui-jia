# 《这就回家》 zhe-jiu-hui-jia

单机 2D 像素游戏：从智利一路徒步回英国。探索 + 生存 + 语言学习。

**第一章《世界的尽头，也是起点》已可玩**：蓬塔阿雷纳斯 → 纳塔莱斯港，沿 Ruta 9 向北，7 个游戏日，正常游玩约 45–55 分钟。

## 怎么玩

- 在线玩：打开本仓库的 GitHub Pages（见仓库主页链接），或把 `index.html` 下载到手机/电脑，用浏览器直接打开——单文件，无依赖。
- 操作：WASD / 方向键走动，空格或点按互动；手机自动显示虚拟方向键。
- 每天：起床先摸膝盖（关节疼 = 天气预报）→ 上路、学西语、遇事件 → 到达夜宿点扎营睡觉 → 下一天。
- 资源：体力 / 食物 / 钱（比索）/ 心情。学会的西语词会解锁对话选项；你做过的事，会被 NPC 记住，并在第七天码头兑现。

## 第一章内容

- 8 个场景、9 位 NPC、24 个西语词（全部绑定真实使用场景）
- 5 个人性事件（分面包 / 路边的钱包 / 搭车抉择 / 雨夜的毯子 / 最后一块面包），无善恶值，只有延迟后果
- 6 个随机小事件、关节报雨系统、词库小测、章节结算（"被谁记住了"清单）
